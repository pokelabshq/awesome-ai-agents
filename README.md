## Frameworks

- [LangChain](https://github.com/langchain-ai/langchain) — Build context-aware reasoning applications
- [AutoGen](https://github.com/microsoft/autogen) — Multi-agent conversation framework
- [CrewAI](https://github.com/crewAIInc/crewAI) — Orchestrating role-playing, autonomous AI agents
- [OpenHands](https://github.com/All-Hands-AI/OpenHands) — AI-powered software development
- [Swarm](https://github.com/openai/swarm) — Multi-agent orchestration by OpenAI

## Agent Infrastructure

- [Conway Cloud](https://conway.cloud) — Sovereign AI agent infrastructure with USDC payments
- [ELIZA OS](https://github.com/elizaOS/eliza) — Operating system for AI agents
- [Morpheus](https://github.com/MorpheusAIs/Morpheus) — Decentralized AI agent network

## Agent Communication

- [x402](https://x402.org) — HTTP-native payments protocol for AI agents
- [ERC-8004](https://eips.ethereum.org/EIPS/eip-8004) — On-chain agent identity and reputation
- [A2A Protocol](https://a2a-protocol.org) — Agent-to-agent communication standard

## Payments & Monetization

- [Agent Payment Node](https://github.com/nuanu-ai/agent-payment-node) — Local CLI and stdio MCP payments on macOS; signing requires foreground owner approval.
- [Base](https://base.org) — Ethereum L2 for fast, cheap USDC transactions
- [Circle USDC](https://www.circle.com/usdc) — Stablecoin for agent payments
- [Poke Labs Services](https://github.com/pokelabshq/services) — 77 zero-dependency microservices with x402 paywalls
